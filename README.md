A curated gallery of **public Claude Opus 5.5 use cases** — playable games, interactive 3D, films, and agents — collected from GitHub, X, and Hacker News, including a dedicated [Videos (from X)](#videos-from-x) section credited to each creator.

*Claude Opus 5.5 公开用例精选：游戏、3D、影像与 Agent 作品合集。*
